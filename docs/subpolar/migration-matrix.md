# Subpolar migration matrix

Source: Subpolar commit `2ddbce819d4a364de075f5d2541eeecb37ac00e8` (`automations`, 2026-10-11). The source checkout has no root license file and its package manifests do not declare a license; provenance is recorded, but redistribution rights remain unverified. This matrix records the current migration decision, not a claim of production readiness.

The inventory categories are: **A** reusable package imported unchanged; **B** reusable package needing dependency/runtime migration; **C** application-backend logic to extract or adapt; **D** already owned by T3 and not duplicated; **E** obsolete frontend-specific code; **F** incomplete work needing further implementation. No source package was imported unchanged: the packages present in T3 have T3-specific dependency, workspace, test, or integration adaptations.

## Package-management notes

T3's `packages/*` pnpm workspace glob includes the imported packages. Keep their `@subpolar/*` package names and valid `workspace:*` dependencies. pnpm is the sole workspace package manager and lockfile owner. Bun remains required for several Subpolar package tests and can serve as the standalone environment manager runtime; T3 server code remains Node.js. The ACP package uses T3's Vite+ runner script, while other imported packages retain Bun test scripts. Frozen, offline lockfile validation succeeded across 40 workspace projects. Package typechecks have not been verified in the current environment.
